# 數學小鎮 🏘

國小數學練習遊戲 — 答題賺金幣，建造你的夢想小鎮！

## 功能
- 📝 9 種題目模式（加減乘除、四則、九九乘法、時鐘）
- 🏠 20+ 種建築，部分建築每日自動產生金幣/EXP
- 🌍 可擴張的土地（最多 8 行 × 5 格 = 40 格）
- 🎮 兩種每日小遊戲（翻牌配對、速算泡泡）
- 🔮 魔法塔：放置後答題金幣 +50%
- 👤 帳號系統：名字 + 4 位 PIN，跨裝置同步

## 部署
上傳所有檔案到 GitHub Pages 即可使用。

## 手寫辨識
使用 Anthropic Claude Vision API 辨識手寫答案。在 claude.ai 中內建使用，外部部署請設定 API key。
